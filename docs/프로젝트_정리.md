# 데이터부동산 — 하고 싶은 것 정리

> 2026-11-25 기준, 대화 내용 정리

## 1. 한 줄 요약
**얼굴, 촬영, 클라이언트 없이 AI와 자동화로 "숫자 중심 부동산 정보" 숏폼과 롱폼 채널을 운영해서 광고와 협찬 수익을 내는 것.**

## 2. 나에 대한 전제
- **본업:** AI 영상 제작자 (개발자가 아님. 코드로 시스템을 구축하지는 못함)
- **시간:** 주 5시간 이상
- **관심 분야:** AI·IT, 맛집·여행, 재테크·생활정보, 육아·건강·뷰티, 부동산, 자동차, 영화

## 3. 하기 싫은 것 (절대 조건)
| 싫은 것 | 이유 |
|---|---|
| 클라이언트 작업 (외주, 대행) | 남의 비위와 니즈를 맞추며 살고 싶지 않음 |
| 강의 | 강의하러 다니고 싶지 않음 |
| 코드로 시스템 구축 (챗봇, RAG 등) | 개발자가 아님 |
| 법·세금·계약 같은 민감한 주제 | 전문가가 아니라서 책임질 수 없음 |
| AI 아바타 진행자 | 활용성이 떨어지고 매번 크레딧이 듦 |
| 블로그 위주 운영 | 블로그보다 영상 플랫폼이 우선 |
| 한 분야로 지나치게 좁히기 | 여러 주제와 채널을 운영하고 싶음 |

## 4. 하고 싶은 것
### 운영하고 싶은 페이지 (여러 개)
1. **부동산·임대 정보** ← 지금 1순위로 제작 중
2. 40~50대 운동·건강식품 정보
3. 자동차
4. 영화 소식
5. AI 정보
6. AI 단편 영상

### 제작 조건
- **실물이 없음:** 실차, 현장 답사, 직접 촬영 없이 만들어야 함
- **화면 소스:** AI 영상 + 공식 자료(보도자료 등) + 공개 데이터 + 3D·실사 느낌의 자료화면
  - HTML 모션그래픽만으로는 부족하고 **실제 지도 위치, 3D, 실사**처럼 보여야 함
- **음성:** 성우 내레이션 필수. **미국식 억양이면 안 됨** (자연스러운 한국어)
- **비용 최소화:** 크레딧이 드는 작업은 최소한으로, 가능한 건 자동화
- **숫자가 훅:** 한국인은 숫자에 반응한다. 첫 1초에 숫자를 넣는다

### 플랫폼 전략
- **숏폼이 우선** (조회수와 성장 속도)
- 롱폼은 제작비 부담이 커서, 숏폼에서 반응이 검증된 주제만 확장
- 주력은 유튜브 (쇼츠 + 롱폼). 40~50대 타깃은 네이버 클립도 고려

## 5. 부동산 채널 방향 (현재 확정)
- **채널명(가칭):** 데이터부동산 — "숫자로 보는 동네 이야기"
- **다루는 것:** 공개 데이터와 공식 발표 기반의 순위, 비교, 변화
- **다루지 않는 것:** 투자 추천, 계약·법률·세금 조언
- **레퍼런스:** 강남코리아(@gnkorea): 하이엔드 부동산, 음성과 공식 자료만 사용
  - 분석 결과: **억 단위 숫자, 극단적인 스펙, "가장 비싼", "최초공개"**가 터지는 공식
  - 우리의 차별점: "집 소개"가 아니라 **"숫자 분석 + 실제 지도 3D"**
  - 주의: 유명인 이름은 보도된 사실만 쓰고, 분양 홍보 영상을 무단으로 쓰지 않음

## 8. 수익 구조 (기대치)
- 숏폼으로 구독자와 노출 확보 → 롱폼 광고 수익 (부동산은 광고 단가가 높음)
- 협찬과 제휴 (클라이언트 작업이 아니라 **내 콘텐츠에 광고가 붙는** 형태)
- 처음 6개월~1년은 수익이 거의 없을 수 있음을 전제로 함
